CrazyGames store media for Rite Brawl
====================================

Upload these files on the CrazyGames developer portal. Do not upload
source .gd files or the GitHub zip here.

Covers (all three are required)
-------------------------------
cover_landscape_1920x1080.png   Landscape 16:9
cover_portrait_800x1200.png     Portrait 2:3
cover_square_800x800.png        Square 1:1

Only the game title is on the covers (no Play Now / New).

Hover / preview videos (both required)
--------------------------------------
hover_landscape_1920x1080.mp4   1080p 16:9, silent, under 20 seconds
hover_portrait_1080x1620.mp4    1080p 2:3, silent, under 20 seconds

CrazyGames cuts videos longer than 20 seconds. These have no sound,
no mouse cursor, and open on the matching cover image.
