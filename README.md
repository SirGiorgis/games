# Games

## Paper Copy Trader

Local **paper-trading** copy-trading simulator. Virtual €500 account, no real orders.

See [paper-copy-trader/README.md](paper-copy-trader/README.md). On Windows: `cd paper-copy-trader` then `start.bat`.

## Ashen Rite (Godot 4.4)

Original 2D arcade fighter. Open `ashen-rite/project.godot` in Godot 4.4 and press Play.

Full notes: [ashen-rite/README.md](ashen-rite/README.md)

## Duel video

Fan-made cinematic from a still. Rebuild with `python3 scripts/assemble_duel.py`.
